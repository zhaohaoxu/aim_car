# 硬件资料

本目录存放小车硬件相关的参考图，均为立创 LCKFB-TMX-MSPM0G3507 底板资料。

| 文件 | 内容 |
| --- | --- |
| `images/schematic-main.png` | 嘉立创 EDA 原理图（main 图页，含排针定义、按键、UART、OLED、陀螺仪、循迹、LED、通信模块） |
| `images/pcb-layout.webp` | PCB 布线图，用于核对走线与器件位置 |
| `images/board-render.png` | 底板 3D 渲染图，用于辨认板载接口与丝印 |

引脚分配与模块说明以工程代码和 `empty_mspm0g3507.syscfg` 为准。
